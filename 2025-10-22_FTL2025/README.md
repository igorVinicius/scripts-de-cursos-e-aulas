# Oficina FTL 2025 — Qualidade do ar

Ambiente Python do notebook `FTL2025_qualidadeDoAr_rev1.ipynb`, gerenciado com [uv](https://docs.astral.sh/uv/).

Para executar no Google Colab, abra o notebook pelo badge no topo do arquivo.

## Como usar

1. Clone o repositório e entre na pasta da oficina:

   ```bash
   git clone https://github.com/igorVinicius/scripts-de-cursos-e-aulas.git
   cd scripts-de-cursos-e-aulas/2025-10-22_FTL2025
   ```

2. Instale as dependências (cria o ambiente `.venv`):

   ```bash
   uv sync
   ```

3. Abra o notebook com o Jupyter, usando o ambiente do projeto:

   ```bash
   uv run --with jupyter jupyter lab
   ```
